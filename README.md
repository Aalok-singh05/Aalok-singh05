## Projects

**[Nexus](https://github.com/Aalok-singh05/Nexus)** — Multi-Agent AI Event Management System `2026`

5 specialized agents (scheduler, mailer, budget, analytics, content) orchestrated via LangGraph with graph-based execution. Integrates Google Calendar API for schedule sync, Gemini API for LLM reasoning, and supports "what-if" simulation for dynamic event changes. Deployed on Vercel for real-time conversational planning.

`Python` `LangGraph` `Gemini API` `Google Calendar API` `Vercel`

---

**[BharatBiz](https://github.com/Aalok-singh05/BHARAT-BIZ)** — Business Automation Backend `2026`

Scalable FastAPI backend for end-to-end business operations — customers, orders, invoices, inventory. Includes WhatsApp API integration for automated notifications, AI-driven analytics via prompt-based systems, and Docker containerization for consistent deployment.

`Python` `FastAPI` `Docker` `WhatsApp API` `REST APIs`

---

**[StaySphere](https://github.com/Aalok-singh05/StaySphere)** — Full-Stack Accommodation Platform `2025`

RESTful API-driven MVC application for property listing and booking. Features geospatial search with Leaflet + MapTiler, Cloudinary-optimized media delivery, and server-side rendering via EJS.

`Node.js` `Express.js` `MongoDB` `Leaflet.js` `Cloudinary` `Mapbox`
